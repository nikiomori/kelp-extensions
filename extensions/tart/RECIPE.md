# Install Virtual Machines (Tart) with your agent

Say to the agent in Kelp:

> Add the Virtual Machines (Tart) extension to Kelp: run `kelp ext install tart`.

It installs [Virtual Machines (Tart)](README.md) from Kelp's extension library, after showing what it runs. It needs `tart` on this Mac; the agent can install that too.
