# Docker

Containers: logs, a shell inside, start / stop, and compose.

Needs `docker` — Kelp keeps it off until that's installed.

Adds a **Containers** panel to the right inspector, refreshed every 5 s.
Double-click a row for **Logs**; its context menu also has Open Shell, Start, Stop, Restart, Remove, Ask Agent About It.
Toolbar: Compose Up, Prune.

In the command palette (⇧⌘P): Docker: Compose Up.
