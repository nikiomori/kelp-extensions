# Install Virtual Machines (UTM) with your agent

Say to the agent in Kelp:

> Add the Virtual Machines (UTM) extension to Kelp: run `kelp ext install utm`.

It installs [Virtual Machines (UTM)](README.md) from Kelp's extension library, after showing what it runs. It needs `/Applications/UTM.app/Contents/MacOS/utmctl` on this Mac; the agent can install that too.
