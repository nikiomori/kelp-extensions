# Virtual Machines (UTM)

Start, stop and suspend UTM virtual machines.

Needs [UTM](https://mac.getutm.app) in /Applications — Kelp keeps it off until it is there.

Adds a **Virtual Machines** panel to the right inspector, refreshed every 5 s.
Double-click a row for **Start**; its context menu also has Stop, Suspend, Show in UTM.
